# Соответствие имён инструментов

В инструкции ниже инструменты названы так, как их называет автор инструкции. В этой среде они называются иначе или состоят из нескольких вызовов:

- `get_pr_diff` — это инструмент `pull_request_read` с параметром `method: "get_diff"`. Остальные параметры (владелец, репозиторий, номер PR) смотри в описании инструмента.
- `get_file_contents` — инструмент с тем же именем. Параметр `ref` — строка вида `refs/heads/<ветка>`.
- `read_legal_docs` — это два вызова: сначала `list_directory` с путём `/docs`, затем один вызов `read_multiple_files` со списком всех `.md`-файлов из `/docs`. Для лимита вызовов оба вместе считаются одним `read_legal_docs`.
- `get_package_info` — инструмент с тем же именем, параметр `package_name`.

Лимиты и правила из инструкции действуют без изменений.
